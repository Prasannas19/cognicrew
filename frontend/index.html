Research topic

What is double buffering in computer graphics?

No documents required: when Web Search is enabled, Exa queries verified live academic sources.

Synthesized Answer

Double buffering is a graphics rendering technique that eliminates tearing and visual artifacts by writing to a back buffer and swapping it to the screen upon completion.

[1] wikipedia.org — Multiple buffering
[2] docs.gl — OpenGL Buffer swap behavior

1. Executive Overview: Buffer Architecture

Chapter 12

In computer animation and graphical UI rendering, double buffering prevents flickering by creating two memory buffers. Graphics primitives are written to the back buffer in system memory or VRAM, then swapped in a single vertical sync cycle.

Key Takeaway: Frame swaps synchronized with V-Sync eliminate horizontal tearing artifacts completely.

Core Definitions

  • Back Buffer: Offscreen memory buffer where rendering draws.
  • Page Flip: Instant pointer swap between back and front buffer.
